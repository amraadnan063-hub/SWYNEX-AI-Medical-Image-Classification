# AI-Powered Medical Image Classification System

### A Deep Learning-Based Chest X-ray Classification Project

## About the Project

The AI-Powered Medical Image Classification System is a machine learning project that aims to classify chest X-ray images into two categories: Normal and Pneumonia.

The project explores the use of Artificial Intelligence, Deep Learning, and Computer Vision to identify visual patterns in medical images through automated image classification.

This application is being developed as part of the SWYNEX Technologies Artificial Intelligence Internship.

## Project Objectives

- Develop an AI-based medical image classification system.
- Explore Convolutional Neural Networks (CNNs).
- Process and classify chest X-ray images.
- Evaluate model performance using standard classification metrics.
- Develop a user-friendly application for image classification.

## Planned Features

- Chest X-ray image upload.
- Automated image classification.
- Normal and Pneumonia category prediction.
- Prediction confidence score.
- User-friendly application interface.

## Dataset

This project uses the **Chest X-Ray Images (Pneumonia)** dataset by Paul Mooney, available on Kaggle.

- **Dataset Link:** https://www.kaggle.com/datasets/paultimothymooney/chest-xray-pneumonia
- **Original Source:** Mendeley Data
- **DOI:** 10.17632/rscbjbr9sj.2
- **Reported Images:** 5,863
- **Image Format:** JPEG
- **Classes:** NORMAL and PNEUMONIA
- **License:** CC BY 4.0

### Dataset Structure

- `train/` – Training images
- `test/` – Testing images
- `val/` – Validation images

Each folder contains `NORMAL` and `PNEUMONIA` subfolders.

The dataset folder structure and image availability have been verified locally.
